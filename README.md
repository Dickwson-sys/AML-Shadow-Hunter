# AML Shadow Hunter

## Overview
**AML Shadow Hunter** is a final year software engineering project designed to detect and investigate suspicious patterns and activities. 

## Features
* **Backend:** Robust server-side logic, data ingestion pipelines, and database management.
* **Frontend:** Interactive user interface with responsive form validation and dynamic data views.
* **Containerization:** Fully configured with Docker for seamless deployment and environment management.

## Tech Stack
* **Languages:** JavaScript, Python, HTML/CSS
* **Database & Architecture:** Docker Compose, Node/Django environments (configured via backend/frontend setup)

## Getting Started

### Prerequisites
Make sure you have the following installed on your machine:
* Node.js & npm
